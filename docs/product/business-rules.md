# Business Rules

This document owns approved business constraints. It does not define endpoint behavior, persistence, UI composition, or current implementation status. Product capability requirements are in [Requirements](requirements.md); business capability ownership is in [Roles and Permissions](roles-and-permissions.md).

## Recruitment contact

Employer access to a nurse candidate's contact information follows the nurse's approval of a recruitment contact request. Candidate discovery alone does not grant contact access.

## Preparation-package composition and sale

- A preparation package is one commercially offered product alongside standalone paid mock-exam access. It is scoped to one examination's country and exam category, has one package-level price, and includes exactly one published mock exam in v1. Its four benefits are materials, practice, one package-scoped exam attempt, and one analytical report. Buyers do not select or purchase the benefits separately in v1.
- Package definition, published package version, and sellable offer are distinct business concepts. A published version fixes one exact published exam version, a compatible immutable reporting-profile publication, an ordered list of specific published material versions, and one published practice-collection version. V1 composition selects the complete published practice-collection version, not individual practice items, and uses ordered material versions directly rather than a material-collection abstraction. An offer selects an already-published package version and sets price, currency, and access duration. At most one offer is active per Preparation Package definition in v1.
- A package version cannot be published with a missing, draft, retired, or incompatible required component. If a required component later becomes ineligible, dependent offers are not available for new sales. Existing purchased composition, entitlements, and reports are not rewritten by that change.
- A package order item preserves the purchased offer's identity, package-version reference, price, currency, and display facts at order creation. Later catalog changes do not rewrite that purchase record or its entitlement.
- An authorized package administrator manages composition and publication separately from offer and pricing administration. Offer administration does not independently choose component content or reporting topics.
- The normal/base commercial price and a promotional adjustment are distinct concepts. Approved promotion administration is scoped to Preparation Packages; [Roles and Permissions](roles-and-permissions.md) owns the administrator capability. No discount calculation or eligibility rule is established here.

## Materials, practice, and reporting topics

- Study materials are managed content with their own publication lifecycle. Published material versions are immutable and reusable across packages; revisions create new versions. Only published material versions may enter a published package version. A package version uses an ordered list of exact material versions. Draft material content is not available to nurses.
- V1 material types are File, External link, Video, and Formatted text. Material access ends with the package access window. Interactive lessons, per-material progress, and offline material access are outside v1.
- Practice items are distinct from official exam questions. Practice collections have reusable immutable published versions. A v1 package includes one published practice-collection version. Practice gives immediate feedback; the exam does not give immediate pre-completion feedback. Practice must not reveal the included exam's protected questions, options, answer keys, explanations, rationales, or snapshots.
- A practice item included in a v1 package maps to exactly one reporting topic. Each included material version may map to one or more reporting topics. Each reporting topic belongs to one exam category. A compatible immutable reporting-profile publication binds topic assignments to the exact published exam version included in the package, without changing that exam version. Every scored question required for package eligibility has exactly one reporting-topic assignment.
- Basic practice progress distinguishes unanswered, answered-correct, and answered-incorrect items. Practice retry or re-answer is allowed while practice access is active and never consumes the package exam attempt. Practice performance does not alter official exam scoring or provide evidence for the v1 analytical report. After access expires, new practice actions stop; historical practice progress may remain visible to the owning nurse.

## Purchase, entitlement, and access window

- Standalone exam access retains its separate effective-paid classification: `Exam.IsFree == false` or an active positive-price `ExamAccess` product exists for that exam. Preparation Package offers, entitlements, attempts, and benefit rights do not enter that classification; a standalone `ExamAccessGrant` is evidence used for standalone authorization, not an input to the classification. Package eligibility and purchase rights are evaluated separately.
- Successful fulfillment of one package order item creates one nurse-owned package purchase entitlement with independently authorizable materials, practice, exam-attempt, and report rights. Repeating fulfillment for the same order item cannot create another entitlement. A package entitlement is traceable to its fulfilled order item and purchased-offer snapshot.
- The single package access window begins at successful fulfillment and lasts for the duration configured on the purchased offer. It does not begin at checkout or first use. Materials and practice require an active window; creation of a package exam session requires an active window and unused package attempt.
- A nurse cannot repurchase the same stable package while an entitlement for that package is active. Repurchase after expiry establishes a separate purchase, access window, attempt, and report right. Different packages containing the same exam may coexist.
- Existing standalone exam access and package rights remain independent. Standalone ownership does not block package purchase, and package ownership does not block standalone purchase. A standalone exam session does not consume or qualify a package attempt or report right. A package attempt does not become a standalone exam-access grant.

## Package exam attempt and report

- A package attempt is consumed only when its qualifying exam session is successfully created. A failed start does not consume it. The nurse selects the specific package purchase; the product does not silently select an entitlement or switch access sources.
- A nurse may have only one in-progress session for the same exam version across free, standalone, and package sources. Retrying the same package source resumes its existing valid in-progress session; a conflicting different source has a deterministic conflict outcome. Session source and purchase provenance do not change after creation.
- If the package expires after successful session creation, the nurse may still resume, submit, or reach automatic finalization under the exam session's own timer. Expiry does not consume another attempt or remove eligibility for the package report.
- A finalized submitted or expired qualifying package session qualifies for one nurse-owned, immutable analytical report. An abandoned session does not qualify. A first valid report request may generate that report after package access expires, and a generated report remains readable after expiry. Report-generation failure cannot undo finalized exam scoring, permanently consume the report right, or require an exam retake; generation remains recoverable.
- The v1 report uses qualifying exam evidence, not practice performance. Its deterministic guidance may reference only the material versions and practice-collection version included in the purchased package version. It does not disclose exam question text, protected options, correct-answer identifiers, rationales, or per-question review. It is not an AI recommendation.
