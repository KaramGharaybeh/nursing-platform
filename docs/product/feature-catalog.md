# Feature Catalog

This catalog groups approved product features by purpose. It does not report implementation progress, schedule releases, or adopt design proposals. [Requirements](requirements.md) owns required outcomes; [Business Rules](business-rules.md) owns the constraints on them.

| Product domain | Approved feature scope |
|---|---|
| Accounts | Registration, sign-in, email verification, and account/password recovery. |
| Nurse professional profile | Personal and professional profile information, experience, education, certificates, languages, skills, CV, and recruitment visibility. |
| Employer profile and recruitment | Employer/organization information, candidate search and filtering, contact requests, and nurse-controlled approval of contact access. |
| Mock examinations | Exam discovery and participation, timed mock-exam sessions, scoring, results, review, and performance analytics; examination-content administration. |
| Standalone exam commerce | Paid standalone mock-exam access through a product, order, checkout, and fulfillment path. |
| Preparation-package catalog | Stable package identity, immutable published package composition, and sellable offers. |
| Preparation-package content | Managed study materials, independent practice items and reusable practice collections, reporting topics, and compatible reporting-profile publication. |
| Preparation-package access | Purchase entitlement with materials, practice, one package-scoped exam attempt, and one analytical-report right; a package workspace concept that brings those benefit entry points together. |
| Preparation-package reporting | Numeric exam-based diagnostic reporting and guidance restricted to purchased content; [Requirements](requirements.md) owns the required v1 output. |
| Preparation-package promotions | Authorized administration of discounts, promotional offers, and promo codes for Preparation Packages. Detailed promotion mechanics are not yet approved. |
| Administration | Authorized management of users, examinations, reference information, preparation-package content, publication, offers, and Preparation Package promotions. |

The first commercial preparation-package scope excludes multi-exam or cross-country bundles, subscriptions, multiple-benefit selection at purchase, multiple package attempts, adaptive practice, AI recommendations, and reports combining practice performance with exam evidence. Their appearance in a design or long-term vision does not make them approved current features.
