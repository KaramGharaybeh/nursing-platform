# Product Glossary

These are shared business concepts. The labels do not prescribe class, table, endpoint, or UI names. Their governing constraints are in [Business Rules](business-rules.md).

| Term | Product meaning |
|---|---|
| Nurse | A person using examination-preparation and professional-profile capabilities and receiving recruitment contact requests. |
| Employer | A healthcare organization user seeking nurse candidates for recruitment. |
| Mock exam | An examination-preparation experience that simulates a nursing licensing examination. |
| Standalone exam access | Access purchased for an exam independently of a preparation package. |
| Preparation package | One commercially offered product combining study materials, practice, one package-scoped mock-exam attempt, and one analytical report. |
| Package definition | The stable business identity of a preparation package across its versions and offers. |
| Published package version | An immutable, validated selection of one published exam version, a compatible reporting-profile publication, specified published material versions, and one published practice-collection version. |
| Package offer | The sellable choice of an already-published package version with price, currency, and access duration. |
| Purchased-offer snapshot | The package-offer facts preserved for an order item when that item is created. |
| Package purchase entitlement | The nurse-owned result of successful fulfillment of a package order item, giving rise to the package's benefit rights. |
| Benefit right | One independently authorizable part of a package entitlement: materials, practice, exam attempt, or report. |
| Access window | The period beginning at successful package fulfillment during which window-limited package benefits may be used. |
| Practice item | An independently managed question for practice, distinct from an official mock-exam question. |
| Practice collection version | An immutable published set of practice items reusable in package versions. |
| Material version | An immutable published form of managed study content reusable in package versions. |
| Reporting topic | A category-scoped subject used to connect scored questions and purchased preparation content for report guidance. |
| Reporting-profile publication | An immutable topic-assignment publication compatible with one exact published exam version and separate from that exam version. |
| Qualifying package session | A package-attempt exam session finalized as submitted or expired and eligible for its package report. |
| Analytical report | The immutable, nurse-owned diagnostic output from one qualifying package session. |
| Preparation Package promotion | A commercial adjustment or promotional offer for a Preparation Package; the approved capability includes discounts and promo codes without prescribing their calculation or eligibility rules. |
